# Full-body action concepts

Five minimal-style sheets cover all 21 current characters, in the same groups and left-to-right order as the committed portrait masters. Open index.html for names, actions and identity comparisons. The source portraits, crop alignments and original SVG renderer remain separate.

Generated using the built-in image generator. The corresponding portrait master controls character identity; ../style-reference.png controls full-body proportions and rendering. prompts.json contains the exact prompts and reference roles; actions.json records actions and worldbook sources. generation-records.json records output hashes and dimensions; reference-hashes.json records the input snapshot.

These are posed concepts rather than new canon or gameplay assets. Workwear and lower-body costumes extend the committed upper-body designs. The artwork is stored in the repository folder for review; this pass does not create a Git commit or wire it into the game.
