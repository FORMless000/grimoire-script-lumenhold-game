# Event classes

> Every event declares `class:` and `tone:` (phase 3 annotated all older content); lint checks the class budgets with the preview engine.

| Class | Rule | Measured |
|---|---|---|
| `routine` | no option obviously best (one at least as good as another on every value and better on one, neither risky; `costs.md`); each within ±1.5 medium-equivalents. A free option is fine beside one that gives something else. A routine card tagged `placeholder` (a stand-in for content still to write, playtest 2 I7) is listed by lint instead of judged | per event |
| `milestone` | may be pure reward; capped at 2 large | per run: count and value |
| `incident` | may be all-negative; must offer agency (mitigate vs accept) | per run: about 1–3 serious ones a year |
| `windfall` | may be all-positive; capped at 1 large | per run: frequency band |
| `story` | exempt from the budget; reviewed by the critic | per arc |
| `crisis` | exempt | rate per play style |

**Tones** (`@vocab tones`): light, warm, tense, grim, eerie. The director avoids two cards of the same tone or primary tag in a row.

**Weights** (how often an eligible event is drawn): default 10; milestones 18–30, so they appear soon after they unlock; niche events 6–8.
