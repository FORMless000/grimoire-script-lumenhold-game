# Event classes

> **Status: phase 2a.** `class:` and `tone:` become required fields in schema v1. Write events with a class in mind now; phase 3 annotates the existing corpus.

| Class | Rule | Measured |
|---|---|---|
| `routine` | strict budget: at least one cost or risky branch; within ±1.5 medium-equivalents | per event |
| `milestone` | may be pure reward; capped at 2 large | per run: count and value |
| `incident` | may be all-negative; must offer agency (mitigate vs accept) | per run: about 1–3 serious ones a year |
| `windfall` | may be all-positive; capped at 1 large | per run: frequency band |
| `story` | exempt from the budget; reviewed by the critic | per arc |
| `crisis` | exempt | rate per play style |

**Tones** (`@vocab tones`): light, warm, tense, grim, eerie. The director avoids two cards of the same tone or primary tag in a row.
