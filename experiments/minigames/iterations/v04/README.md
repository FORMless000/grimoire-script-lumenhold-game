## Search budgets and validation

Search policy `alpha-beta-2` keeps the combat rules and evaluator unchanged. Setup now separates behavior (full/shallow/fallible) from computation: **Fast 100 ms** (default) or **Deep 500 ms**. These are cooperative whole-decision deadlines in the existing worker; they include any exact mistake-ranking search. Timed results can vary with device speed. Shallow behavior still caps nominal depth at one exchange. On seeded mistake attempts, half the compute budget is reserved for exact ranking so a deep search cannot silently disable fallibility. An unfinished ranking keeps the main action.

Programmatic calls without a compute profile retain depth 3 / 5,000 nodes and a fixed horizon. `chooseAIAction(state, {computeProfile:'analyst'})` requests six nominal exchanges / 200,000 total nodes, no clock deadline, and tactical horizons. `live_fast` and `live_deep` request up to eight nominal exchanges with ceilings of 1,000,000 and 5,000,000 nodes. A tactical horizon may add one full exchange for an active channel, a due Omen or construct expiry. It cannot extend repeatedly.

`createSearchContext({tableLimit})` supplies an optional third argument to `searchAction(state, options, context)` and `chooseAIAction(state, overrides, context)`. Contexts are external to game state, per actor and encounter; the browser and simulation adapter manage them. They retain collision-verified numeric position keys, best moves, horizon-specific bounds, ordering history and reusable state buffers. Changed encounter inputs invalidate cached data. `horizonMode:'fixed'`, `pvs:false`, and `aspiration:false` support reference checks. `budgetMs` and an injectable `now()` support deadline tests.

From the repository root, each command writes a new output directory and refuses to overwrite an existing one:

```sh
node experiments/minigames/bench-v04-search.mjs --mode fixed --out /private/tmp/search-fixed
node experiments/minigames/bench-v04-search.mjs --mode nodes --nodes 5000 --out /private/tmp/search-nodes
node experiments/minigames/bench-v04-search.mjs --mode live_fast --out /private/tmp/search-fast
node experiments/minigames/bench-v04-search.mjs --mode live_deep --out /private/tmp/search-deep
node experiments/minigames/converge-v04-search.mjs --out /private/tmp/search-convergence
```

The benchmark freezes its source inputs, uses 48 deterministic public positions at levels 20/50/80, reports warmed latency/depth/work counters, and separately measures cold Node-worker module startup. Run timing benchmarks alone. A desktop mobile-sized viewport checks layout, not actual phone performance. The frozen pre-optimization engine in `reference/v04-search-046/` is a validation oracle, never a shipped dependency.

The full generic panel is a separately invoked, potentially long balance experiment (108 fights per command):

```sh
node experiments/minigames/run-v04-random.mjs --panel generic --compute-profile live_fast --workers 4 --out /private/tmp/panel-fast
node experiments/minigames/run-v04-random.mjs --panel generic --compute-profile live_deep --workers 4 --out /private/tmp/panel-deep
node experiments/minigames/run-v04-random.mjs --panel generic --compute-profile analyst --workers 4 --out /private/tmp/panel-analyst
node experiments/minigames/analyze-v04-random.mjs /private/tmp/panel-analyst --no-benchmark
node experiments/minigames/converge-v04-search.mjs --run /private/tmp/panel-analyst --out /private/tmp/panel-convergence
```

The analyzer reports wins, censoring, action use, achieved depths and latency under worker contention. A work-limit unfinished fight is not a draw. Convergence defaults to 50,000 / 200,000 / 1,000,000 nodes, up to depth eight, with the Analyst table capacity of 65,536 positions (`--table-limit` overrides it). It reports value changes and regret at a common reference depth only when a full exact root ranking completed; otherwise regret is unavailable. These diagnostics do not establish balance by themselves. Use the legacy compute profile for explicit `--depth`/`--nodes` panel settings. Rust, evaluation fitting, selective action pruning and campaign packaging remain deferred.

For a load-controlled comparison, alternate the frozen baseline and optimized search in one process:

```sh
node experiments/minigames/bench-v04-search.mjs --mode nodes --repeats 1 --reference experiments/minigames/reference/v04-search-046 --paired-reference --out /private/tmp/search-paired
node experiments/minigames/compare-v04-search.mjs /private/tmp/search-paired/reference-decisions.json /private/tmp/search-paired/decisions.json /private/tmp/search-paired-comparison.json
```

Paired output includes wall time and process CPU time, raw per-decision checkpoints, source/runner hashes, and a frozen reference. `--mode timed --budget-ms 100` (or 500) compares fixed horizons; its reference copy adds only a deadline check to the old search. The `live_fast`/`live_deep` modes measure the actual tactical profiles separately. For convergence, `--fixture-ids 20-opening-commit,50-channel-respond,80-omen-respond` selects explicit public positions.
